## 1. 프로젝트 개요와 진행 상황

### 1-1. 프로젝트
- 이름: **Monochrome Gallery** — 3층짜리 VR 미술관 (Unity 6000.3.19f1, URP, OpenXR)
- 플랫폼: **Meta Quest 2(안드로이드)** + **PC(키보드·마우스)** 동시 지원. 헤드셋이 켜지면 자동으로 VR 모드(`VRRig`).
- 콘셉트: 1층 파스텔 → 2층 컬러 일러스트 → 3층 흑백. 목표 문구 "게임목표는 3층까지 관람하는 것".
- 패키지명: `com.miga.gallery`, 제품명 "Monochrome Gallery".
- 씬: `Assets/Scenes/MainMenu.unity`(메인 메뉴) → `Assets/Scenes/Scene_01_Main.unity`(본 게임). Build Profiles 순서: MainMenu, Scene_01_Main, SampleScene.

### 1-2. 게임 흐름 (현재 구현 상태)
1. **메인 메뉴**: 티켓 이미지(`ui_ticket_blank`) 위 로고, 목표 문구, Start/Quit. (`MainMenuManager`)
2. **시작 안내 팝업**: 게임 씬 시작 시 티켓 종이에 "관람 안내 / 게임목표는 3층까지 관람하는 것 / 조작법 / 관람 시작". 뒤는 85% 어둡게. (`IntroPanel`)
3. **입구 문**(`InteractDoor`, `Door_Entrance`)을 열면 1층 BGM 시작, 문 소리. 문은 플레이어 반대쪽으로 열림(`DoorSwing`).
4. **층 이동 문**(`FloorDoor`, 계단실 문): 문 열림 연출 없음.
   - 1층 문 → 바로 2층 / 3층 문 → 바로 2층 / **2층 문 → "어디로 갈까요?" 창(3층으로 올라가기 / 1층으로 내려가기 / 취소)** (`FloorChoiceUI`)
   - 도착 위치: 1층 `Spawn_F1_Stairs`(-15.4, 1.0, -6.5), 2층 `Spawn_F2`(-4.95, 6.94, -5.0, yaw 90), 3층 `Spawn_F3`(-1.5, 16.94, 1.2, yaw 285)
5. **층별 BGM**(`BGMManager`): 층이 바뀌면 이전 곡 즉시 Stop, 새 곡 Loop 재생(페이드 없음). 1층 `BGM_F1`(viacheslavstarostin 473993, 112초), 2층 `BGM_F2`(floor_2.mp3, 84초), 3층 `BGM_F3`(floor_3.mp3, 47초).
6. **그림 크게 보기**(`PaintingViewer`): 그림 클릭/VR 트리거 → 눈앞으로 확대, 다시 누르면 복귀.
7. **2층 그림 탈출 연출**(`PaintingEscape` + `ButterflyFlight`): 붓꽃 그림(`picture_2_8`)과 여자 그림(`picture_2_4`)에 파란 나비 2마리씩. 6m 안에서 그림을 바라보면 캔버스 물결(`PaintingRipple.shader`) → 나비가 빠져나와 **플레이어 머리 주변을 따라다니다 2~3초 뒤 빛 가루로 사라짐**. 멀어지면(9m) 그림 위로 복귀, 다시 오면 반복.
8. **3층 엔딩**: 나가는 문 앞의 책 받침대(`F3_EndingBookStand`, 일반 고서 + 흑백 빈티지 재질, 기둥 연장). 가까이서 E / VR 트리거 → **"게임 종료"** 티켓 패널(메인 메뉴로 / 종료하기) + 엔딩 효과음 `BGM_Ending`(1.5초). (`EndingBook`)
9. **효과음**(`GameSfx`): 문 소리 `Assets/@Audio/DoorSound.mp3`(입구는 3D, 계단실 문은 2D), 발소리 `WalkSound.wav` 0.6초 간격(볼륨 0.75).
10. **VR 조작**(`VRRig`): 왼쪽 스틱 이동 / **오른쪽 스틱 하나로 다 가능**(위아래 걷기, 좌우 스무스 회전 — 미는 만큼 비례, `turnCurve 1.8`) / 트리거 클릭. 메뉴가 떠 있으면 레이저가 벽을 무시하고 버튼에 닿음. 거리 판정은 머리 위치 기준(`GameLoopManager.PlayerPosition`).
11. 이동 속도: PC `PlayerMovement.speed` 6, VR `moveSpeed` 2.0. 눈높이: PC 카메라 local Y 1.9(바닥에서 약 2.8m), VR `defaultEyeHeight` 2.72(1.6배 상향 요청 반영).

### 3-1. `Assets/@Scripts/GameLoop/GameLoopManager.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Events;
using UnityEngine.InputSystem;

// 층별 스테이지 순환 루프
//  [퀴즈 끔 — 기본] 계단실 문(FloorDoor)으로 바로 위·아래층으로 이동 (1층→2층, 2층→3층/1층 선택, 3층→2층). 3층 엔딩 책에서 게임 종료
//  [퀴즈 켬] 탐색(ObservationPoint 전부 관찰) → 퀴즈 창 자동 오픈 → 정답 → 다음 층 해제 → ...
//           Tab(또는 Q)로 언제든 퀴즈 창을 열고 닫을 수 있다.
//  화면 중앙(조준점)으로 클릭하면 문(IPointerTarget)·QuizClickTarget을 찾는다. VR에서는 VRRig의 레이저가 대신한다.
public class GameLoopManager : MonoBehaviour
{
    public static GameLoopManager Instance { get; private set; }

    [Header("Mode")]
    [Tooltip("끄면 퀴즈 없이 문만 열면 다음 층으로 이동")]
    public bool useQuiz = false;

    [Header("Stages (아래층부터 순서대로)")]
    public List<FloorStage> stages = new List<FloorStage>();

    [Header("Player")]
    public Transform player;
    public Camera playerCamera;
    [Tooltip("퀴즈 창이 열려 있는 동안 꺼 둘 컴포넌트 (이동·시점 회전 등)")]
    public List<Behaviour> disableWhileUIOpen = new List<Behaviour>();

    [Header("Input")]
    public Key toggleKey = Key.Tab;
    public Key altToggleKey = Key.Q;
    [Range(1f, 20f)] public float clickDistance = 8f;

    [Header("Teleport")]
    [Tooltip("마지막 층 정답 후 이동할 위치 (1층 출입문 안쪽)")]
    public Transform finalSpawnPoint;
    [Range(0f, 3f)] public float teleportDelay = 1.6f;   // 성공 연출을 보여 준 뒤 이동
    [Range(0.05f, 2f)] public float fadeTime = 0.45f;

    [Header("Events")]
    public UnityEvent<int> onFloorUnlocked;   // 해제된 층 번호(1부터)
    public UnityEvent onGameCleared;

    // 거리 판정용 플레이어 위치 (발 높이). VR에서는 방 안을 실제로 걸어 다니면 리그 중심과 머리가 어긋나므로 머리의 수평 위치를 쓴다
    public Vector3 PlayerPosition
    {
        get
        {
            if (player == null) return Vector3.zero;
            if (!VRRig.IsActiveNow) return player.position;
            var h = VRRig.Current.head.transform.position;
            return new Vector3(h.x, player.position.y, h.z);
        }
    }

    public QuizUI UI { get; private set; }
    public FloorStage CurrentStage { get; private set; }
    public bool IsTeleporting { get; private set; }

    void Awake()
    {
        Instance = this;

    void UpdateCurrentStage()
    {
        if (player == null) return;
        float y = player.position.y;
        FloorStage found = null;
        foreach (var s in stages)
            if (s.IsUnlocked && y >= s.minY && y < s.maxY) found = s;
        if (found == CurrentStage) return;

        CurrentStage = found;
        if (found != null && !found.IsSolved)
            UI.Toast(found.Quiz != null ? $"{found.floorNumber}층 — {found.Quiz.Title}" : $"{found.floorNumber}층", 3f);

    {
        if (!useQuiz) return;

        if (kb == null) return;
        if (!kb[toggleKey].wasPressedThisFrame && !kb[altToggleKey].wasPressedThisFrame) return;
        // 입력칸에 글자를 치는 중에는 Q 토글 무시
        if (UI.IsTyping && kb[altToggleKey].wasPressedThisFrame) return;

        else if (CurrentStage != null && CurrentStage.Quiz != null) UI.Open(CurrentStage.Quiz);

        var mouse = Mouse.current;

        var ray = playerCamera.ViewportPointToRay(new Vector3(0.5f, 0.5f, 0f));
        if (!Physics.Raycast(ray, out var hit, clickDistance, ~0, QueryTriggerInteraction.Collide)) return;
        var pointerTarget = PointerTargetLink.Find(hit.collider);
        if (pointerTarget != null) { pointerTarget.OnPointerClick(player.position); return; }
        var target = hit.collider.GetComponentInParent<QuizClickTarget>();
        if (target != null) target.Click();

    public List<FloorStage> Destinations(FloorStage stage)

        var list = new List<FloorStage>();
        int idx = stages.IndexOf(stage);
        if (idx < 0) return list;
        if (idx < stages.Count - 1) list.Add(stages[idx + 1]);
        if (idx > 0) list.Add(stages[idx - 1]);
        return list;

    public void PassDoor(FloorStage stage)

        if (dests.Count == 0) return;
        if (dests.Count == 1) { GoToFloor(stage, dests[0]); return; }

        var options = new List<FloorChoiceUI.Option>();
        foreach (var d in dests)
        {
            var target = d;
            string verb = d.floorNumber > stage.floorNumber ? "올라가기" : "내려가기";
            options.Add(new FloorChoiceUI.Option($"{d.floorNumber}층으로 {verb}", () => GoToFloor(stage, target)));
        }
        FloorChoiceUI.Show(this, "어디로 갈까요?", options);

    public void GoToFloor(FloorStage from, FloorStage to)
    {
        if (IsTeleporting || to == null) return;
        from.MarkSolved();
        if (!to.IsUnlocked)
        {
            to.SetUnlocked(true);
            onFloorUnlocked?.Invoke(to.floorNumber);
        }
        GameSfx.PlayDoor();   // 계단실 문을 열고 나가는 소리 (화면이 어두워지는 동안)
        var point = to.stairArrival != null ? to.stairArrival : to.spawnPoint;
        StartCoroutine(TeleportRoutine(point, $"{to.floorNumber}층", 0f));
    }

    public void NotifyExplorationComplete(FloorStage stage)
    {

    public void NotifyStageSolved(FloorStage stage)
    {
        int idx = stages.IndexOf(stage);
        bool last = idx == stages.Count - 1;

        if (last)
        {
            // 1층 출입문 안쪽으로 이동 → 출입문 밖(ExitZone)으로 나가면 클리어
            UI.Celebrate("정답!\n이제 탈출할 수 있어요.");
            StartCoroutine(TeleportRoutine(finalSpawnPoint, "1층 출입문으로 나가 미술관을 빠져나가세요."));
            return;
        }

        var next = stages[idx + 1];
        next.SetUnlocked(true);
        UI.Celebrate($"정답!\n{next.floorNumber}층으로 이동해요.");
        onFloorUnlocked?.Invoke(next.floorNumber);
        StartCoroutine(TeleportRoutine(next.spawnPoint, $"{next.floorNumber}층 — {next.Quiz?.Title}. 그림을 둘러보고 계단실 문에서 [E]를 누르세요."));
    }

    // 이미 푼 층의 문에서 E를 다시 눌렀을 때: 다음 층으로 이동만
    public void GoToNextFloor(FloorStage solved)
    {
        int idx = stages.IndexOf(solved);
        var target = idx == stages.Count - 1 ? finalSpawnPoint : stages[idx + 1].spawnPoint;
        StartCoroutine(TeleportRoutine(target, null, 0f));
    }

    // 화면을 어둡게 → 플레이어 위치·방향 이동 → 다시 밝게
    System.Collections.IEnumerator TeleportRoutine(Transform target, string arrivalToast, float delay = -1f)
    {
        if (target == null || player == null) yield break;
        while (IsTeleporting) yield return null;   // 앞선 이동이 끝날 때까지 기다렸다가 이어서
        IsTeleporting = true;
        yield return new WaitForSecondsRealtime(delay < 0f ? teleportDelay : delay);

        UI.Close();
        yield return UI.Fade(1f, fadeTime);

        var cc = player.GetComponent<CharacterController>();
        if (cc != null) cc.enabled = false;               // CharacterController가 위치 변경을 덮어쓰지 않게
        player.SetPositionAndRotation(target.position, Quaternion.Euler(0f, target.eulerAngles.y, 0f));
        if (VRRig.IsActiveNow) VRRig.Current.AlignHeadTo(target.position, target.eulerAngles.y);   // 방 안에서 걸어 다닌 만큼 어긋난 머리 위치 보정
        else if (playerCamera != null) ResetPitch();
        if (cc != null) cc.enabled = true;
        UpdateCurrentStage();

        yield return new WaitForSecondsRealtime(0.15f);
        yield return UI.Fade(0f, fadeTime);
        IsTeleporting = false;
        if (!string.IsNullOrEmpty(arrivalToast)) UI.Toast(arrivalToast, 5f);
    }

    // 카메라 상하 각도를 수평으로 (MouseLook의 내부 각도 값도 함께)
    void ResetPitch()
    {
        playerCamera.transform.localRotation = Quaternion.identity;
        foreach (var b in playerCamera.GetComponents<MonoBehaviour>())
        {
            var f = b != null ? b.GetType().GetField("xRotation", System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance) : null;
            if (f != null && f.FieldType == typeof(float)) f.SetValue(b, 0f);
        }
    }

    // 최종 출구 문을 열었을 때 (InteractDoor.isExit)
    public void CompleteGame()
    {
        UI.Celebrate("탈출 성공!\n미술관 밖으로 나왔어요.");
        onGameCleared?.Invoke();
    }

    // 퀴즈 창이 열리면 이동·시점을 멈추고 커서를 보여 준다
    void SetPlayerControl(bool uiOpen)
    {
        foreach (var b in disableWhileUIOpen) if (b != null) b.enabled = !uiOpen;
        Cursor.lockState = uiOpen ? CursorLockMode.None : CursorLockMode.Locked;
        Cursor.visible = uiOpen;
    }
}
```

```csharp
    public UnityEvent onSolved;

    public bool IsSolved { get; private set; }
    public bool ExplorationDone { get; private set; }
    public FloorQuiz Quiz => quiz;
    public GameLoopManager Manager { get; private set; }

    public int RequiredCount => Mathf.CeilToInt(observationPoints.Count * requiredRatio);

    public void Init(GameLoopManager manager, int number)
    {
        Manager = manager;
        floorNumber = number;
        if (observationPoints.Count == 0) observationPoints = GetComponentsInChildren<ObservationPoint>(true).ToList();
        if (!manager.useQuiz) quiz = null;   // 퀴즈 끔: 문만 열면 이동
```

```csharp
using UnityEngine;
using UnityEngine.InputSystem;

// 층 이동 문(계단실 문): 문이 열리는 연출 없이 바로 층 이동.
//  갈 수 있는 층이 하나면(1층→2층, 3층→2층) 바로 이동하고, 둘이면(2층→3층/1층) 고르는 창(FloorChoiceUI)을 띄운다.
//  - 데스크톱: 문 앞에서 E/F, 또는 조준점으로 문 클릭
//  - VR: 레이저로 문을 가리키고 트리거
public class FloorDoor : MonoBehaviour, IPointerTarget
{
    public FloorStage stage;
    [Tooltip("문짝 (클릭·레이저가 맞을 콜라이더가 있는 오브젝트)")]
    public Transform doorLeaf;

    [Header("Interaction")]
    public Key interactKey = Key.E;
    public Key altInteractKey = Key.F;
    [Tooltip("이 거리(수평) 안에서만 쓸 수 있다 — VR 레이저도 동일")]
    [Range(0.5f, 6f)] public float interactRadius = 3f;
    [Range(0.5f, 5f)] public float maxHeightDiff = 2.5f;

    [Header("Text")]
    public string promptDesktop = "[ E ]  {0}";
    public string promptVR = "트리거  —  {0}";
    public string promptLocked = "아직 이 층에 올 수 없어요";
    public string tooFarToast = "문 가까이 가서 눌러 주세요";

    static FloorDoor promptOwner;   // 가장 가까운 문 하나만 안내

    void Awake()
    {
        if (doorLeaf == null) return;
        PointerTargetLink.Attach(doorLeaf.gameObject, this);
        // 에셋 기본 문 스크립트가 같은 클릭으로 문을 여닫지 않게 끈다
        var legacy = doorLeaf.GetComponent<SojaExiles.opencloseDoor>();
        if (legacy != null) legacy.enabled = false;
    }

    Vector3 Center
    {
        get
        {
            var t = doorLeaf != null ? doorLeaf : transform;
            var r = t.GetComponentInChildren<Renderer>();
            return r != null ? r.bounds.center : t.position;
        }
    }

    float Dist(Vector3 p) { var c = Center; return new Vector2(p.x - c.x, p.z - c.z).magnitude; }

    bool IsNear(Vector3 p) => Dist(p) <= interactRadius && Mathf.Abs(p.y - Center.y) <= maxHeightDiff;

    string Prompt(GameLoopManager m)
    {
        if (!stage.IsUnlocked) return promptLocked;
        return string.Format(VRRig.IsActiveNow ? promptVR : promptDesktop, m.DestinationText(stage));
    }

    void Update()
    {
        var m = GameLoopManager.Instance;
        if (m == null || m.player == null || stage == null) return;

        var p = m.PlayerPosition;
        bool near = !m.UI.IsOpen && !m.IsTeleporting && !PaintingViewer.IsBusy && !FloorChoiceUI.IsOpen && IsNear(p);

        if (near && (promptOwner == null || promptOwner == this || Dist(p) < promptOwner.Dist(p)))
        {
            promptOwner = this;
            m.UI.ShowPrompt(Prompt(m));
        }
        else if (promptOwner == this && !near)
        {
            promptOwner = null;
            m.UI.HidePrompt();
        }

        if (promptOwner != this || !near) return;
        var kb = Keyboard.current;
        if (kb != null && (kb[interactKey].wasPressedThisFrame || kb[altInteractKey].wasPressedThisFrame)) TryOpen();
    }

    public void OnPointerClick(Vector3 playerPosition) => TryOpen();

    public void TryOpen()
    {
        var m = GameLoopManager.Instance;
        if (m == null || m.IsTeleporting || FloorChoiceUI.IsOpen || stage == null) return;
        if (!stage.IsUnlocked) { m.UI.Toast(promptLocked, 2f); return; }
        if (!IsNear(m.PlayerPosition)) { m.UI.Toast(tooFarToast, 2f); return; }
        if (promptOwner == this) { promptOwner = null; m.UI.HidePrompt(); }
        m.PassDoor(stage);
    }

    void OnDisable()
    {
        if (promptOwner == this) { promptOwner = null; GameLoopManager.Instance?.UI.HidePrompt(); }
    }

    void OnDrawGizmosSelected()
    {
        Gizmos.color = Color.cyan;
        Gizmos.DrawWireSphere(Center, interactRadius);
    }
}
```

```csharp
        public Action onChoose;

    }

    public static bool IsOpen => instance != null && instance.canvas.gameObject.activeSelf;

    static readonly Color Ink = new Color(0.1f, 0.07f, 0.05f, 1f);
    static readonly Color Paper = new Color(0.95f, 0.91f, 0.84f, 1f);

    GameLoopManager manager;

    RectTransform card, backdrop;
    Text titleText;
    readonly List<GameObject> buttons = new List<GameObject>();
    List<Option> current;
    int openedFrame;

    public static void Show(GameLoopManager m, string title, List<Option> options)
    {
        if (instance == null)
        {
            instance = new GameObject("FloorChoiceUI").AddComponent<FloorChoiceUI>();
            instance.transform.SetParent(m.transform, false);
            instance.Build();
        }
        instance.manager = m;
        instance.Open(title, options);
    }

    void OnDestroy() { if (instance == this) instance = null; }

    void Open(string title, List<Option> options)
    {
        current = options;
        titleText.text = title;
        foreach (var b in buttons) Destroy(b);
        buttons.Clear();

        var font = QuizUI.LoadKoreanFont(40);
        float gap = 110f, top = (options.Count - 1) * gap * 0.5f + 10f;
        for (int i = 0; i < options.Count; i++)
        {
            int index = i;
            buttons.Add(MakeButton(options[i].label, font, new Vector2(0, top - i * gap), new Vector2(560, 90), Ink, Paper, () => Choose(index)));
        }
        buttons.Add(MakeButton("취소", font, new Vector2(0, -205), new Vector2(220, 64), new Color(Ink.r, Ink.g, Ink.b, 0.55f), Paper, Close));

    void Choose(int index)
    {
        var o = current[index];
        Close();
        o.onChoose?.Invoke();
    }

    void Close()
    {
        if (!canvas.gameObject.activeSelf) return;
        canvas.gameObject.SetActive(false);
        SetDesktopControl(true);
    }

    void Update()
    {
        if (!IsOpen || Time.frameCount == openedFrame) return;   // 창을 연 키 입력은 무시
        var kb = Keyboard.current;
        if (kb == null) return;
        if (kb.escapeKey.wasPressedThisFrame) { Close(); return; }
        for (int i = 0; i < current.Count && i < 9; i++)
            if (kb[Key.Digit1 + i].wasPressedThisFrame || kb[Key.Numpad1 + i].wasPressedThisFrame) { Choose(i); return; }

    {

        foreach (var b in manager.disableWhileUIOpen) if (b != null) b.enabled = on;
        Cursor.lockState = on ? CursorLockMode.Locked : CursorLockMode.None;
        Cursor.visible = !on;

    void PlaceInFront(VRRig rig)
    {
        if (canvas.renderMode != RenderMode.WorldSpace)
        {
            XRCanvasAdapter.ToWorldSpace(canvas, rig.head, 1.4f);
            backdrop.anchorMin = backdrop.anchorMax = new Vector2(0.5f, 0.5f);
            backdrop.sizeDelta = new Vector2(40000f, 40000f);   // 주변을 어둡게
        }
```

```csharp
using System.Collections;
using UnityEngine;

// 문짝을 경첩(피벗) 기준으로 플레이어 반대쪽(안쪽)으로 회전시킨다. FloorDoor·InteractDoor 공용.
public static class DoorSwing
{
    // 열린 회전값: center(문짝 중심)가 플레이어에게서 멀어지는 방향으로 angle만큼
    public static Quaternion AwayFrom(Transform leaf, Vector3 center, Vector3 player, float angle)
    {
        var hinge = leaf.position;
        var toCenter = center - hinge; toCenter.y = 0f;
        var toPlayer = player - hinge; toPlayer.y = 0f;
        float sign = Vector3.Dot(Quaternion.AngleAxis(angle, Vector3.up) * toCenter, toPlayer) < 0f ? 1f : -1f;
        return Quaternion.AngleAxis(angle * sign, Vector3.up) * leaf.rotation;
    }

    public static IEnumerator Rotate(Transform leaf, Quaternion to, float duration)
    {
        var from = leaf.rotation;
        for (float t = 0f; t < 1f; t += Time.deltaTime / Mathf.Max(0.01f, duration))
        {
            leaf.rotation = Quaternion.Slerp(from, to, Mathf.SmoothStep(0f, 1f, t));
            yield return null;
        }
        leaf.rotation = to;
    }

    // 문짝이 움직이는 동안 플레이어(CharacterController)를 밀지 않게 콜라이더를 끄고 켠다
    public static void SetColliders(Transform leaf, bool on)
    {
        foreach (var c in leaf.GetComponentsInChildren<Collider>()) c.enabled = on;
    }
}
```

```csharp
// 효과음: 문 여는 소리 + 발걸음 소리
//  - 문: InteractDoor(입구)가 열릴 때, 계단실 문으로 층을 옮길 때 GameSfx.PlayDoor 호출

public class GameSfx : MonoBehaviour
{
    public static GameSfx Instance { get; private set; }

    [Header("Door")]
    public AudioClip doorSound;
    [Range(0f, 1f)] public float doorVolume = 0.8f;

    [Header("Footsteps")]
    public AudioClip walkSound;
    [Range(0f, 1f)] public float walkVolume = 0.5f;
    [Tooltip("걷는 동안 한 걸음 소리 간격 (초) — 클수록 천천히 걷는 느낌")]
    [Range(0.25f, 1.5f)] public float stepInterval = 0.6f;
    [Tooltip("이 속도(m/s) 이상으로 움직일 때만 걷는 것으로 본다")]
    public float minSpeed = 0.3f;
    [Tooltip("걸음마다 음높이를 조금씩 바꿔 기계적으로 들리지 않게")]
    [Range(0f, 0.3f)] public float pitchVariation = 0.08f;

    AudioSource feet, ui;
    CharacterController body;
    Vector3 lastPos;
    float walked;

    void Awake()
    {
        Instance = this;
        feet = gameObject.AddComponent<AudioSource>();
        feet.playOnAwake = false;
        feet.spatialBlend = 0f;   // 내 발소리는 2D
        ui = gameObject.AddComponent<AudioSource>();   // 순간이동해도 끊기지 않는 2D 효과음 (계단실 문)
        ui.playOnAwake = false;
        ui.spatialBlend = 0f;
    }

    void Start()
    {
        var m = GameLoopManager.Instance;
        if (m != null && m.player != null)
        {
            body = m.player.GetComponent<CharacterController>();
            lastPos = m.player.position;
        }
    }

    // pos가 있으면 문 위치에서 3D로, 없으면 플레이어 귀에 2D로 재생
    // (계단실 문은 소리가 시작되자마자 다른 층으로 순간이동하므로 2D로 따라가게 한다)
    public static void PlayDoor(Vector3? pos = null)
    {
        var s = Instance;
        if (s == null || s.doorSound == null) return;
        if (pos.HasValue) AudioSource.PlayClipAtPoint(s.doorSound, pos.Value, s.doorVolume);
        else s.ui.PlayOneShot(s.doorSound, s.doorVolume);
    }

    void Update()
    {
        var m = GameLoopManager.Instance;
        if (m == null || m.player == null || walkSound == null) return;

        var p = m.player.position;
        var delta = p - lastPos;
        lastPos = p;
        delta.y = 0f;
        float d = delta.magnitude;

        // 순간이동·층 이동(한 프레임에 크게 움직임)이나 공중에 있을 때는 세지 않는다
        bool grounded = body == null || body.isGrounded || Physics.Raycast(p, Vector3.down, 1.2f, ~0, QueryTriggerInteraction.Ignore);
        if (m.IsTeleporting || d > 1.5f || !grounded) { walked = 0f; return; }

        // 움직이는 동안 일정한 박자로 (속도와 상관없이 느긋한 관람 걸음)
        if (d < minSpeed * Time.deltaTime) { walked = Mathf.Min(walked, stepInterval * 0.5f); return; }   // 멈췄다 다시 걸으면 반 박자 뒤 첫 걸음
        walked += Time.deltaTime;
        if (walked < stepInterval) return;
        walked = 0f;
        feet.pitch = 1f + Random.Range(-pitchVariation, pitchVariation);
        feet.PlayOneShot(walkSound, walkVolume);
    }
}
```

```csharp
    void FollowHead()
    {
        if (body == null) return;
        var local = transform.InverseTransformPoint(head.transform.position);
        body.center = new Vector3(local.x, bodyCenterY, local.z);

    void Move()
    {
        if (body == null || !body.enabled) return;
        var input = moveAction.ReadValue<Vector2>();
        if (input.magnitude < deadZone) input = Vector2.zero;
        if (rightHandMove && input == Vector2.zero)
        {
            // 오른쪽 스틱 위/아래 = 앞뒤로 걷기 (좌우는 Turn에서 방향 돌리기)
            float y = turnAction.ReadValue<Vector2>().y;
            if (Mathf.Abs(y) > deadZone) input = new Vector2(0f, y);
        }
        input = Vector2.ClampMagnitude(input, 1f);

        var yaw = Quaternion.Euler(0f, head.transform.eulerAngles.y, 0f);
        var move = yaw * new Vector3(input.x, 0f, input.y) * moveSpeed;
        fallSpeed = body.isGrounded ? -2f : fallSpeed + gravity * Time.deltaTime;
        body.Move((move + Vector3.up * fallSpeed) * Time.deltaTime);
    }

    void Turn()
    {
        var stick = turnAction.ReadValue<Vector2>();
        float x = stick.x;
        // 오른손으로 걸을 때: 스틱이 위아래 쪽으로 더 기울어 있으면 걷는 중이니 회전은 약하게 (대각선으로 밀면 걸으면서 천천히 돈다)
        if (rightHandMove && Mathf.Abs(stick.y) > Mathf.Abs(stick.x)) x *= 0.5f;
        if (snapTurn)
        {
            if (!turnLatched && Mathf.Abs(x) > 0.7f) { RotateAroundHead(Mathf.Sign(x) * snapAngle); turnLatched = true; }
            else if (Mathf.Abs(x) < 0.3f) turnLatched = false;
        }
        else
        {
            // 데드존 밖에서 0→1로 다시 매핑한 뒤 곡선 적용: 살짝 밀면 천천히, 끝까지 밀면 최고 속도
            float a = Mathf.Clamp01((Mathf.Abs(x) - deadZone) / (1f - deadZone));
            float target = Mathf.Sign(x) * Mathf.Pow(a, turnCurve) * smoothTurnSpeed;
            turnVelocity = Mathf.Lerp(turnVelocity, target, 1f - Mathf.Exp(-turnResponse * Time.deltaTime));
            if (Mathf.Abs(turnVelocity) > 0.5f) RotateAroundHead(turnVelocity * Time.deltaTime);
        }
    }

    // 머리 추적이 시작되고 잠시 뒤 한 번, 눈높이를 defaultEyeHeight로 맞춘다 (이후 숙이기·앉기는 그대로 반영)
    void CalibrateEyeHeight()
    {
        if (!forceEyeHeight || calibrateAt == float.MaxValue) return;
        if (calibrateAt < 0f)
        {
            if (head.transform.localPosition != Vector3.zero) calibrateAt = Time.time + 0.5f;   // 추적 시작 감지
            return;
        }
        if (Time.time < calibrateAt) return;
        RecalibrateEyeHeight();
        calibrateAt = float.MaxValue;
    }

    [ContextMenu("Recalibrate Eye Height")]
    public void RecalibrateEyeHeight()
    {
        if (CameraOffset == null) return;
        var p = CameraOffset.localPosition;
        p.y = FeetOffset + defaultEyeHeight - head.transform.localPosition.y;
        CameraOffset.localPosition = p;
    }

    // 머리 위치를 축으로 회전 (회전할 때 몸이 옆으로 밀리지 않게)
    void RotateAroundHead(float angle)
    {
        var pivot = head.transform.position;
        var rot = Quaternion.Euler(0f, angle, 0f);
        var newPos = pivot + rot * (transform.position - pivot);
        transform.rotation = rot * transform.rotation;
        var delta = newPos - transform.position;
        delta.y = 0f;
        if (body != null && body.enabled) body.Move(delta);
        else transform.position += delta;
    }

    // 순간이동 직후: 머리가 목표 지점·방향에 오도록 리그를 맞춘다 (GameLoopManager에서 호출)
    public void AlignHeadTo(Vector3 position, float yaw)
    {
        var headForward = Vector3.ProjectOnPlane(head.transform.forward, Vector3.up);
        float headYaw = Vector3.SignedAngle(transform.forward, headForward, Vector3.up);
        transform.rotation = Quaternion.Euler(0f, yaw - headYaw, 0f);
        var h = head.transform.position;
        transform.position += new Vector3(position.x - h.x, 0f, position.z - h.z);
    }

    // ---------- 레이저 ----------

    void UpdatePointer(Hand h, bool frozen)
    {
        var ray = new Ray(h.t.position, h.t.forward);
        float dist = pointerLength;
        IPointerTarget target = null;

        var button = frozen ? null : FindButton(ray, ref dist);
        // 메뉴(시작 안내·층 선택·엔딩)가 떠 있으면 항상 맨 앞에 그려지므로, 사이에 벽·책 같은 물체가 있어도 버튼을 누를 수 있게
        bool menuOpen = IntroPanel.IsOpen || FloorChoiceUI.IsOpen || EndingBook.IsShowing;
        if (menuOpen && button == null) dist = Mathf.Min(dist, 3f);
        if (!(menuOpen && button != null) && RaycastWorld(ray, dist, out var hit))
        {
            dist = hit.distance;
            button = null;
            target = frozen || menuOpen ? null : PointerTargetLink.Find(hit.collider);   // 메뉴가 떠 있을 땐 뒤의 문·그림은 안 눌리게
        }
        SetHover(h, button);

        bool hover = target != null || button != null;
        var c = hover ? pointerHoverColor : pointerColor;
        h.line.startColor = c;
        h.line.endColor = hover ? c : new Color(c.r, c.g, c.b, 0f);
        h.line.SetPosition(0, ray.origin);
        h.line.SetPosition(1, ray.GetPoint(dist));

        if (frozen || !h.click.WasPressedThisFrame()) return;
        if (button != null) button.onClick.Invoke();
        else if (target != null)
        {
            var m = GameLoopManager.Instance;
            target.OnPointerClick(m != null ? m.PlayerPosition : transform.position);   // 방 안에서 걸어 다닌 만큼 머리 위치 기준
        }
    }

    // 플레이어 자신의 콜라이더는 건너뛰고 가장 가까운 물체
    bool RaycastWorld(Ray ray, float maxDist, out RaycastHit nearest)
    {
        nearest = default;
        int n = Physics.RaycastNonAlloc(ray, hits, maxDist, ~0, QueryTriggerInteraction.Ignore);
        float best = float.MaxValue;
        for (int i = 0; i < n; i++)
        {
            if (hits[i].transform.IsChildOf(transform) || hits[i].distance >= best) continue;
            best = hits[i].distance;
            nearest = hits[i];
        }
        return best < float.MaxValue;
    }

    // World Space 캔버스의 버튼 중 레이저가 닿는 것
    Button FindButton(Ray ray, ref float dist)
    {
        if (Time.unscaledTime >= nextButtonScan)
        {
            buttons = FindObjectsByType<Button>(FindObjectsSortMode.None);
            nextButtonScan = Time.unscaledTime + 0.25f;   // 메뉴가 뜨자마자 버튼이 눌리도록 자주 갱신
        }

        Button best = null;
        foreach (var b in buttons)
        {
            if (b == null || !b.isActiveAndEnabled || !b.interactable) continue;
            var canvas = b.GetComponentInParent<Canvas>();
            if (canvas == null || canvas.renderMode != RenderMode.WorldSpace) continue;

            var rt = (RectTransform)b.transform;
            if (!new Plane(rt.forward, rt.position).Raycast(ray, out float d) || d > dist) continue;
            Vector2 local = rt.InverseTransformPoint(ray.GetPoint(d));
            if (!rt.rect.Contains(local)) continue;
            best = b;
            dist = d;
        }
        return best;
    }

    static void SetHover(Hand h, Button b)
    {
        if (h.hovered == b) return;
        if (h.hovered != null) h.hovered.transform.localScale = Vector3.one;
        h.hovered = b;
        if (b != null) b.transform.localScale = Vector3.one * 1.08f;
    }
}
```

```csharp
            ? hit.point : b.center + Vector3.down * b.extents.y;

        BuildIdleSparkle();

    {
        var m = GameLoopManager.Instance;
        var player = m != null ? m.player : null;
        var cam = VRRig.IsActiveNow ? VRRig.Current.head : (m != null ? m.playerCamera : Camera.main);
        if (player == null || cam == null) return;

        var c = painting.bounds.center;
        float dist = new Vector2(player.position.x - c.x, player.position.z - c.z).magnitude;
        bool sameFloor = Mathf.Abs(player.position.y - floorPoint.y) < 3f;
        bool inFront = Vector3.Dot(player.position - c, normal) > 0f;
        if (dist > resetRadius || !sameFloor) out_ = true;

        // 사라진 나비는 플레이어가 멀어졌을 때 그림 위로 조용히 되돌려 둔다 (다시 오면 연출 반복)
        if (out_ && !armed && butterflies.TrueForAll(b => b.IsGone))
        {
            foreach (var b in butterflies) b.Respawn();
            armed = true;
        }

        foreach (var b in butterflies) { b.followTarget = cam.transform; b.followPlayer = followPlayer; }

        bool allHome = butterflies.TrueForAll(b => b.IsHome);
        if (idleSparkle != null)
        {
            var e = idleSparkle.emission;
            e.enabled = allHome;
        }

        if (armed && out_ && allHome && sameFloor && inFront && dist <= triggerRadius)
        {
            var toPainting = (c - cam.transform.position).normalized;
            if (Vector3.Dot(cam.transform.forward, toPainting) >= lookThreshold) StartCoroutine(Escape(m));
        }

        if (!vanishAfterFlight && flyingSince >= 0f && flightDuration > 0f && Time.time - flyingSince > flightDuration)
        {
            flyingSince = -1f;
            StartCoroutine(ReturnHome());
        }
    }

    IEnumerator Escape(GameLoopManager m)
    {
        armed = false;
        out_ = false;
        if (m != null && !string.IsNullOrEmpty(escapeToast)) m.UI.Toast(escapeToast, 2.5f);

        for (int i = 0; i < butterflies.Count; i++)

            StartCoroutine(Ripple(restSpots[i]));

            butterflies[i].EscapeOut();
            if (vanishAfterFlight) StartCoroutine(VanishLater(butterflies[i]));
            yield return new WaitForSeconds(escapeStagger);
        }
        flyingSince = Time.time;
    }

    // 그림 밖으로 빠져나오는 동작(약 1.6초)이 끝난 뒤 2~3초 날다가 사라진다
```

```csharp
using UnityEngine;

// 나비 한 마리: 그림 표면에 붙어 은은히 빛나다가(Rest) → 그림 밖으로 빠져나와(Escape) → 전시실 공중을 부드럽게 날아다니고(Fly)
// → 시간이 되면 그림으로 돌아가 다시 붙는다(Return). PaintingEscape가 생성·제어한다.
// 프리팹 구조: 루트(이 컴포넌트, +Z가 머리·+Y가 등) / Model(Animation) / Trail(ParticleSystem)
public class ButterflyFlight : MonoBehaviour
{
    public enum State { Rest, Escape, Fly, Return, Vanish, Gone }

    [Header("Flight")]
    [Range(0.3f, 4f)] public float speed = 1.4f;
    [Tooltip("초당 방향을 틀 수 있는 각도")]
    [Range(30f, 360f)] public float turnRate = 140f;
    [Tooltip("날갯짓에 맞춘 위아래 출렁임")]
    [Range(0f, 0.5f)] public float bobAmount = 0.12f;
    [Range(0.5f, 6f)] public float bobSpeed = 3.2f;

    [Header("Wing")]
    [Tooltip("그림에 붙어 있을 때 쓸 날갯짓 클립 시간 (날개가 가장 활짝 펴진 순간)")]
    public float restPoseTime = 0.72f;
    [Tooltip("그림에 붙어 있을 때 날개를 아주 살짝 여닫는 폭 (클립 시간, 초)")]
    [Range(0f, 0.3f)] public float restSway = 0.06f;
    [Range(0.05f, 3f)] public float restFlapSpeed = 0.4f;
    [Range(0.5f, 4f)] public float flyFlapSpeed = 1.6f;

    public State Current { get; private set; } = State.Rest;
    public bool IsHome => Current == State.Rest;

    // PaintingEscape가 지정
    [HideInInspector] public Vector3 restPosition;
    [HideInInspector] public Vector3 surfaceNormal;
    [HideInInspector] public Bounds flyArea;
    [HideInInspector] public Transform followTarget;   // 가끔 이 주변(플레이어 머리)을 맴돈다
    [HideInInspector] public bool followPlayer;        // 켜면 날아다니는 내내 플레이어 머리 주변을 따라다닌다

    [Header("Follow Player")]
    [Tooltip("플레이어 머리 주변을 도는 반경 (m)")]
    [Range(0.3f, 3f)] public float followRadius = 0.9f;
    [Tooltip("머리 기준 높이 (m) — 음수면 눈 아래")]
    public float followHeight = -0.2f;
    [Tooltip("주변을 도는 빠르기 (도/초)")]
    [Range(10f, 180f)] public float orbitSpeed = 70f;
    [Tooltip("플레이어에게 다가갈 때 최고 속도 (m/s)")]
    [Range(1f, 8f)] public float followMaxSpeed = 4f;
    float orbitAngle;

    Animation anim;
    ParticleSystem trail;
    Vector3 pos, vel, target, escapeFrom, escapeTo;
    float t, phase, stateTime, retargetAt;

    void Awake()
    {
        anim = GetComponentInChildren<Animation>();
        trail = GetComponentInChildren<ParticleSystem>();
        phase = Random.value * 10f;
    }

    public void PlaceAtRest(Vector3 position, Vector3 normal)
    {
        restPosition = position;
        surfaceNormal = normal;
        pos = position;
        transform.SetPositionAndRotation(position, RestRotation());
        SetState(State.Rest);
    }

    // 그림에 붙어 있는 자세: 등이 그림 밖(normal)을, 머리가 위를 향한다
    Quaternion RestRotation() => Quaternion.LookRotation(Vector3.ProjectOnPlane(Vector3.up, surfaceNormal).normalized, surfaceNormal);

    public void EscapeOut()
    {
        if (Current != State.Rest) return;
        escapeFrom = restPosition;
        escapeTo = restPosition + surfaceNormal * 1.2f + Vector3.down * 0.4f + Random.insideUnitSphere * 0.3f;
        SetState(State.Escape);
    }

    public void GoHome()
    {
        if (Current == State.Fly) SetState(State.Return);
    }

    public bool IsGone => Current == State.Gone;

    // 날던 자리에서 빛 가루로 흩어지며 사라진다
    public void Vanish()
    {
        if (Current != State.Fly && Current != State.Escape) return;
        vanishScale = transform.localScale;
        if (Current == State.Escape) { pos = transform.position; target = escapeTo + (escapeTo - escapeFrom).normalized; vel = (escapeTo - escapeFrom).normalized * speed; }
        if (trail != null) trail.Emit(25);   // 마지막으로 반짝 흩어지는 빛 가루
        SetState(State.Vanish);
    }

    // 사라진 나비를 그림 위 원래 자리로 되돌린다 (플레이어가 멀리 있을 때)
    public void Respawn()
    {
        if (Current != State.Gone) return;
        transform.localScale = vanishScale;
        SetModelVisible(true);
        PlaceAtRest(restPosition, surfaceNormal);
    }

    Vector3 vanishScale;

    void SetModelVisible(bool on)
    {
        foreach (var r in GetComponentsInChildren<Renderer>(true))
            if (!(r is ParticleSystemRenderer)) r.enabled = on;
    }

    void SetState(State s)
    {
        Current = s;
        stateTime = 0f;
        bool flying = s == State.Escape || s == State.Fly || s == State.Return;
        if (anim != null) foreach (AnimationState a in anim) a.speed = flying ? flyFlapSpeed : 0f;   // 쉴 때는 Update에서 직접 시간 지정
        if (trail != null)
        {
            var e = trail.emission;
            e.enabled = flying;
        }
        if (s == State.Fly) { vel = (escapeTo - escapeFrom).normalized * speed; PickTarget(); }
    }

    void Update()
    {
        float dt = Time.deltaTime;
        t += dt;
        stateTime += dt;

        switch (Current)
        {
            case State.Rest:
                // 그림 위에 날개를 활짝 펴고 붙어서, 아주 살짝 숨 쉬듯 여닫는다
                transform.position = restPosition + surfaceNormal * 0.06f;   // 날개가 캔버스에 파묻히지 않게
                if (anim != null)
                    foreach (AnimationState a in anim)
                        a.time = restPoseTime + Mathf.Sin((t + phase) * restFlapSpeed * Mathf.PI * 2f) * restSway;
                break;

            case State.Escape:
            {
                // 그림 표면에서 스르륵 떨어져 나온다 (처음엔 표면을 따라 미끄러지듯 천천히)
                float k = Mathf.Clamp01(stateTime / 1.6f);
                float e = k * k * (3f - 2f * k);
                pos = Vector3.Lerp(escapeFrom, escapeTo, e);
                var fwd = Vector3.Slerp(Vector3.ProjectOnPlane(Vector3.up, surfaceNormal), (escapeTo - escapeFrom).normalized, e);
                var up = Vector3.Slerp(surfaceNormal, Vector3.up, e);
                transform.SetPositionAndRotation(pos, Quaternion.LookRotation(fwd, up));
                if (k >= 1f) SetState(State.Fly);
                break;
            }

            case State.Fly:
                if (followPlayer && followTarget != null) { Steer(FollowPoint(dt), dt); break; }
                if (Time.time >= retargetAt || (target - pos).sqrMagnitude < 0.36f) PickTarget();
                Steer(target, dt);
                break;

            case State.Vanish:
            {
                // 계속 날면서 0.7초 동안 작아져 사라진다
                Steer(followPlayer && followTarget != null ? FollowPoint(dt) : target, dt);
                float k = Mathf.Clamp01(stateTime / 0.7f);
                transform.localScale = vanishScale * (1f - k * k);
                if (k < 1f) break;
                SetModelVisible(false);
                Current = State.Gone;
                break;
            }

            case State.Return:
            {
                if (landing) { Land(); break; }
                var approach = restPosition + surfaceNormal * 0.8f;
                if ((pos - approach).sqrMagnitude > 0.09f && stateTime < 12f) { Steer(approach, dt); break; }
                // 그림 앞에 오면 표면으로 스르륵 내려앉는다
                landing = true;
                landFrom = pos;
                landRot = transform.rotation;
                stateTime = 0f;
                break;
            }
        }
    }

    bool landing;
    Vector3 landFrom;
    Quaternion landRot;

    void Land()
    {
        float k = Mathf.Clamp01(stateTime / 1.4f);
        float e = k * k * (3f - 2f * k);
        pos = Vector3.Lerp(landFrom, restPosition, e);
        transform.SetPositionAndRotation(pos, Quaternion.Slerp(landRot, RestRotation(), e));
        if (k < 1f) return;
        landing = false;
        SetState(State.Rest);
    }

    void Steer(Vector3 goal, float dt)
    {
        // 플레이어를 따라갈 때는 멀수록 빠르게 (짧은 비행 시간 안에 관람객 곁까지 오도록)
        float s = followPlayer && followTarget != null ? Mathf.Clamp((goal - pos).magnitude * 1.2f, speed, followMaxSpeed) : speed;
        var desired = (goal - pos).normalized * s;
        float turn = followPlayer && followTarget != null ? turnRate * 2f : turnRate;
        vel = Vector3.RotateTowards(vel, desired, turn * Mathf.Deg2Rad * dt, s * 2f * dt);
        if (vel.sqrMagnitude < 0.01f) vel = desired;
        pos += vel * dt;

        // 날갯짓 출렁임 + 진행 방향으로 살짝 기울기
        var shown = pos + Vector3.up * Mathf.Sin((t + phase) * bobSpeed) * bobAmount;
        var flat = Vector3.ProjectOnPlane(vel, Vector3.up);
        var fwd = flat.sqrMagnitude > 1e-4f ? Vector3.Slerp(flat.normalized, vel.normalized, 0.4f) : transform.forward;
        float bank = Vector3.SignedAngle(transform.forward, fwd, Vector3.up) / Mathf.Max(dt, 1e-4f) * -0.05f;
        var rot = Quaternion.LookRotation(fwd, Vector3.up) * Quaternion.Euler(0f, 0f, Mathf.Clamp(bank, -30f, 30f));
        transform.SetPositionAndRotation(shown, Quaternion.Slerp(transform.rotation, rot, 1f - Mathf.Exp(-6f * dt)));
    }

    // 플레이어 머리 주변 원을 따라 도는 목표점 (나비마다 phase로 출발 각도가 다름)
    Vector3 FollowPoint(float dt)
    {
        orbitAngle += orbitSpeed * dt;
        float a = (orbitAngle + phase * 36f) * Mathf.Deg2Rad;
        var h = followTarget.position;
        return new Vector3(h.x + Mathf.Cos(a) * followRadius, h.y + followHeight + Mathf.Sin(a * 1.7f) * 0.15f, h.z + Mathf.Sin(a) * followRadius);
    }

    void PickTarget()
    {
        retargetAt = Time.time + Random.Range(3f, 6f);
        // 가끔은 관람객 주변을 한 바퀴 — 시선을 끌어 준다
        if (followTarget != null && Random.value < 0.35f)
        {
            var off = Random.insideUnitSphere * 1.4f;
            off.y = Mathf.Abs(off.y) * 0.5f + 0.2f;
            target = followTarget.position + off;
            target = flyArea.ClosestPoint(target);
            return;
        }
        target = new Vector3(
            Random.Range(flyArea.min.x, flyArea.max.x),
            Random.Range(flyArea.min.y, flyArea.max.y),
            Random.Range(flyArea.min.z, flyArea.max.z));
    }
}
```

```csharp
using UnityEngine;
#if UNITY_EDITOR
using UnityEditor;
#endif

// 천장 레일 + 와이어 + 앨범을 한 몸으로 제어하는 갤러리 디스플레이.
// 이 오브젝트(Parent)의 위치 = 벽면 위 천장 레일 연결점(Pivot).
// 로컬 축: +Z = 벽 안쪽(앨범 뒷면 방향), -Y = 아래.
//   Parent
//   ├─ RailBar    : 천장에 붙은 가로 레일 (Y 0 ~ -railThickness)
//   ├─ Wire(2)    : 레일 하단 ~ 앨범 상단
//   └─ AlbumFrame : 앨범 (상단 = -heightDistance, 뒷면 = 벽에서 wallOffset)
[ExecuteAlways]
[DisallowMultipleComponent]
public class GalleryDisplay : MonoBehaviour
{
    public enum AlbumOrientation { Horizontal, Vertical }

    [Header("Album")]
    public Transform album;
    public AlbumOrientation orientation = AlbumOrientation.Vertical;
    [Tooltip("세로 모드 앨범 크기 (가로 폭, 세로 높이). 가로 모드는 이 값을 뒤집어 사용")]
    public Vector2 verticalSize = new Vector2(3.1f, 4.9f);

    [Header("Placement")]
    [Tooltip("천장(레일 상단)에서 앨범 상단까지 거리")]
    [Range(0.2f, 9f)] public float heightDistance = 2.25f;
    [Tooltip("벽면에서 앨범 뒷면까지 거리")]
    [Range(0f, 0.5f)] public float wallOffset = 0.04f;

    [Header("Wire")]
    [Range(0.002f, 0.05f)] public float wireThickness = 0.015f;
    [Tooltip("와이어 2줄 간격 = 앨범 폭 x 이 비율")]
    [Range(0f, 1f)] public float wireSpacingRatio = 0.7f;

    [Header("Rail")]
    [Range(0.01f, 0.2f)] public float railThickness = 0.04f;
    [Tooltip("레일이 앨범 양옆으로 더 나가는 길이")]
    [Range(0f, 2f)] public float railMargin = 0.3f;

    [Header("Material (비워두면 어두운 메탈 자동 적용)")]
    public Material metalMaterial;

    [HideInInspector] public Transform railBar, wire, wire2;

    static Material defaultMaterial;

    public Vector2 AlbumSize => orientation == AlbumOrientation.Vertical
        ? verticalSize
        : new Vector2(verticalSize.y, verticalSize.x);

    // 컴포넌트를 처음 붙일 때만 자동 구성 (씬 로드·재컴파일 때는 위치를 건드리지 않음)
    void Reset() => Apply();

#if UNITY_EDITOR
    // OnValidate 안에서 Transform을 바로 바꾸면 경고가 나므로 다음 에디터 틱에 반영
    void OnValidate()
    {
        EditorApplication.delayCall -= DelayedApply;
        EditorApplication.delayCall += DelayedApply;
    }

    void DelayedApply()
    {
        // 편집용 배치 도구 — 플레이 중에는 돌리지 않는다 (정적 배칭으로 메시가 합쳐져 크기를 잘못 재고 그림이 엉뚱한 곳으로 감)
        if (this != null && !EditorApplication.isPlayingOrWillChangePlaymode) Apply();
    }
#endif

    public void Apply()
    {
        EnsureParts();
        Vector2 size = AlbumSize;
        float albumTop = -heightDistance;
        float albumCenterZ = 0f;

        if (album != null)
        {
            // 앨범 원본(스케일 1) 크기를 측정해 목표 크기가 되도록 X, Y 스케일 계산
            album.localRotation = Quaternion.identity;
            Bounds native = MeasureNativeBounds(album);
            var s = album.localScale;
            s.x = size.x / Mathf.Max(native.size.x, 0.0001f);
            s.y = size.y / Mathf.Max(native.size.y, 0.0001f);
            album.localScale = s;

            Vector3 scaledCenter = Vector3.Scale(native.center, s);
            float depth = native.size.z * s.z;
            albumCenterZ = -wallOffset - depth * 0.5f;

            // 상단 = -heightDistance, 가로 중앙 = 0, 뒷면 = -wallOffset
            var target = new Vector3(0f, albumTop - size.y * 0.5f, albumCenterZ);
            album.localPosition = target - scaledCenter;
        }

        // 레일: 천장(0)에 붙은 가로 바
        float railLength = size.x + railMargin * 2f;
        railBar.localPosition = new Vector3(0f, -railThickness * 0.5f, albumCenterZ);
        railBar.localRotation = Quaternion.identity;
        railBar.localScale = new Vector3(railLength, railThickness, railThickness);

        // 와이어: 레일 하단 ~ 앨범 상단
        float wireLength = Mathf.Max(heightDistance - railThickness, 0.001f);
        float spacing = size.x * wireSpacingRatio;
        bool twoWires = spacing > 0.001f;
        FitWire(wire, twoWires ? -spacing * 0.5f : 0f, wireLength, albumCenterZ);
        wire2.gameObject.SetActive(twoWires);
        if (twoWires) FitWire(wire2, spacing * 0.5f, wireLength, albumCenterZ);

        var mat = metalMaterial != null ? metalMaterial : GetDefaultMaterial();
        foreach (var t in new[] { railBar, wire, wire2 })
        {
            var mr = t.GetComponent<MeshRenderer>();
            if (mr != null) mr.sharedMaterial = mat;
        }
    }

    void FitWire(Transform w, float x, float length, float z)
    {
        // Cylinder(높이 2)·Cube(높이 1) 어느 메쉬든 실제 길이가 length가 되도록 메쉬 높이로 나눈다
        var mf = w.GetComponent<MeshFilter>();
        float meshHeight = mf != null && mf.sharedMesh != null ? mf.sharedMesh.bounds.size.y : 2f;

        w.localPosition = new Vector3(x, -railThickness - length * 0.5f, z);
        w.localRotation = Quaternion.identity;
        w.localScale = new Vector3(wireThickness, length / meshHeight, wireThickness);
    }

    // 앨범 하위 메쉬들의 bounds를 앨범 자신의 로컬 공간(스케일 제거)에서 계산
    static Bounds MeasureNativeBounds(Transform root)
    {
        bool has = false;
        var b = new Bounds();
        foreach (var mf in root.GetComponentsInChildren<MeshFilter>(true))
        {
            if (mf.sharedMesh == null) continue;
            var mb = mf.sharedMesh.bounds;
            for (int i = 0; i < 8; i++)
            {
                var corner = mb.center + Vector3.Scale(mb.extents,
                    new Vector3((i & 1) == 0 ? -1 : 1, (i & 2) == 0 ? -1 : 1, (i & 4) == 0 ? -1 : 1));
                var p = root.InverseTransformPoint(mf.transform.TransformPoint(corner));
                if (!has) { b = new Bounds(p, Vector3.zero); has = true; }
                else b.Encapsulate(p);
            }
        }
        return has ? b : new Bounds(Vector3.zero, Vector3.one);
    }

    void EnsureParts()
    {
        if (railBar == null) railBar = transform.Find("RailBar");
        if (railBar == null) railBar = CreatePart(PrimitiveType.Cube, "RailBar");
        if (wire == null) wire = transform.Find("Wire");
        if (wire == null) wire = CreatePart(PrimitiveType.Cylinder, "Wire");
        if (wire2 == null) wire2 = transform.Find("Wire (2)");
        if (wire2 == null) wire2 = CreatePart(PrimitiveType.Cylinder, "Wire (2)");
    }

    Transform CreatePart(PrimitiveType type, string name)
    {
        var go = GameObject.CreatePrimitive(type);
        go.name = name;
        DestroyImmediate(go.GetComponent<Collider>());
        go.transform.SetParent(transform, false);
        return go.transform;
    }

    // #3A3A3A, Metallic 0.9, Smoothness 0.7 (URP Lit, 없으면 Standard)
    static Material GetDefaultMaterial()
    {
        if (defaultMaterial != null) return defaultMaterial;

        var shader = Shader.Find("Universal Render Pipeline/Lit") ?? Shader.Find("Standard");
        var color = new Color32(0x3A, 0x3A, 0x3A, 0xFF);
        defaultMaterial = new Material(shader) { name = "GalleryWire_DarkMetal", hideFlags = HideFlags.DontSave };
        defaultMaterial.SetColor("_BaseColor", color);   // URP
        defaultMaterial.SetColor("_Color", color);       // Standard
        defaultMaterial.SetFloat("_Metallic", 0.9f);
        defaultMaterial.SetFloat("_Smoothness", 0.7f);   // URP
        defaultMaterial.SetFloat("_Glossiness", 0.7f);   // Standard
        return defaultMaterial;
    }

    // Scene 뷰: 노란 구 = 천장 연결점, 빨간 선 = 벽면
    void OnDrawGizmos()
    {
        Gizmos.color = Color.yellow;
        Gizmos.DrawWireSphere(transform.position, 0.06f);
        Gizmos.color = Color.red;
        Gizmos.DrawLine(transform.position, transform.position - transform.up * heightDistance);
    }
}
```

```csharp
    // 화면 오버레이 UI(안내 창·층 선택·엔딩·토스트)를 카메라에 같이 그리도록 잠깐 바꾼다
    static List<(Canvas c, RenderMode mode, Camera cam, float dist)> SwapOverlays(Camera cam)
    {
        var list = new List<(Canvas, RenderMode, Camera, float)>();
        foreach (var c in Object.FindObjectsByType<Canvas>(FindObjectsSortMode.None))
        {
            if (!c.isRootCanvas || c.renderMode != RenderMode.ScreenSpaceOverlay || !c.gameObject.activeInHierarchy) continue;
            list.Add((c, c.renderMode, c.worldCamera, c.planeDistance));
            c.renderMode = RenderMode.ScreenSpaceCamera;
            c.worldCamera = cam;
            c.planeDistance = cam.nearClipPlane + 0.02f + 0.0005f * Mathf.Clamp(1000 - c.sortingOrder, 0, 1000);   // 정렬 순서가 높을수록 앞 (항상 카메라 앞쪽)
        }
        Canvas.ForceUpdateCanvases();
        return list;
    }

    static void RestoreOverlays(List<(Canvas c, RenderMode mode, Camera cam, float dist)> list)
    {
        foreach (var e in list) { if (e.c == null) continue; e.c.renderMode = e.mode; e.c.worldCamera = e.cam; e.c.planeDistance = e.dist; }
    }

    public static Texture2D Render(Camera cam, int w, int h, bool withUI, Texture2D reuse = null)
    {
        var swapped = withUI ? SwapOverlays(cam) : null;
        var rt = RenderTexture.GetTemporary(w, h, 24, RenderTextureFormat.ARGB32, RenderTextureReadWrite.sRGB, 4);
        var prevTarget = cam.targetTexture;
        cam.targetTexture = rt;
        cam.Render();
        cam.targetTexture = prevTarget;
        var prev = RenderTexture.active;
        RenderTexture.active = rt;
        var tex = reuse != null && reuse.width == w && reuse.height == h ? reuse : new Texture2D(w, h, TextureFormat.RGBA32, false);
        tex.ReadPixels(new Rect(0, 0, w, h), 0, 0);
        tex.Apply();
        RenderTexture.active = prev;
        RenderTexture.ReleaseTemporary(rt);
        if (swapped != null) RestoreOverlays(swapped);
        return tex;
    }

    public static string Shot(Camera cam, string name, int w = 1920, int h = 1080, bool withUI = true)
    {
        Directory.CreateDirectory(OutDir);
        var tex = Render(cam, w, h, withUI);
        var path = Path.Combine(OutDir, name + ".png");
        File.WriteAllBytes(path, tex.EncodeToPNG());
        Object.DestroyImmediate(tex);
        return path;
    }

    static Texture2D frameTex;

        Time.captureFramerate = 0;
    }

    // ---------- 투어 (플레이어를 경로대로 걷게) ----------

    public struct Key
    {
        public Vector3 pos; public float yaw, pitch, seconds;   // seconds = 이전 지점에서 여기까지 걸리는 시간 (0이면 순간이동)
        public Key(Vector3 p, float yaw, float pitch, float seconds) { pos = p; this.yaw = yaw; this.pitch = pitch; this.seconds = seconds; }

    static List<Key> keys;
    static int seg;
    static float segT;

    public static void BeginTour(List<Key> path) { keys = path; seg = 1; segT = 0f; Place(keys[0].pos, keys[0].yaw, keys[0].pitch); }

    public static bool TourDone => keys == null || seg >= keys.Count;

    // 한 프레임 진행: 위치·시선을 부드럽게 옮기고 → 게임 1프레임 → 녹화
    public static void TourStep(float dt)
    {
        if (TourDone) return;
        var a = keys[seg - 1]; var b = keys[seg];
        segT += dt;
        float k = b.seconds <= 0f ? 1f : Mathf.Clamp01(segT / b.seconds);
        float e = k * k * (3f - 2f * k);
        Place(Vector3.Lerp(a.pos, b.pos, e), Mathf.LerpAngle(a.yaw, b.yaw, e), Mathf.Lerp(a.pitch, b.pitch, e));
        if (k >= 1f) { seg++; segT = 0f; }
    }

    public static void Place(Vector3 pos, float yaw, float pitch)
    {
        var m = GameLoopManager.Instance;
        var cc = m.player.GetComponent<CharacterController>();
        if (cc) cc.enabled = false;
        m.player.SetPositionAndRotation(pos, Quaternion.Euler(0f, yaw, 0f));
        if (cc) cc.enabled = true;
        var cam = m.playerCamera.transform;
        cam.localRotation = Quaternion.Euler(pitch, 0f, 0f);
        foreach (var b in m.playerCamera.GetComponents<MonoBehaviour>())
        {
            var f = b != null ? b.GetType().GetField("xRotation", System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance) : null;
            if (f != null && f.FieldType == typeof(float)) f.SetValue(b, pitch);
        }
    }
```

```csharp
            var next = index + 1 < shots.Count ? shots[index + 1] : null;
            bool floorEnds = next != null && (next.caption != null || next.card);
            if (newFloor) blackA = Mathf.Max(blackA, 1f - Ramp(local, 0f, 0.6f));
            if (floorEnds && !next.card) blackA = Mathf.Max(blackA, Ramp(local, s.sec - 0.6f, s.sec));
        }

        black.color = new Color(0, 0, 0, blackA);
        title.text = titleText; title.color = new Color(1, 1, 1, titleA);
        subtitle.text = subText; subtitle.color = new Color(0.85f, 0.85f, 0.85f, titleA);

        // 층 자막: 그 층 첫 컷 시작부터 2.8초 동안
        float capA = 0f; string cap = "", capSub = "";
        for (int i = index; i >= 0; i--)
        {
            if (shots[i].card) break;
            if (shots[i].caption == null) continue;
            float since = t - shots[i].start;
            capA = Ramp(since, 0.5f, 1.1f) * (1f - Ramp(since, 3.2f, 3.8f));
            cap = shots[i].caption; capSub = shots[i].sub;
            break;
        }
        caption.text = cap; caption.color = new Color(1, 1, 1, capA);
        captionSub.text = capSub; captionSub.color = new Color(0.9f, 0.9f, 0.9f, capA * 0.9f);
    }

    // ---------- 오디오 ----------

    static float[] Load(string path)
    {
        var imp = (AudioImporter)AssetImporter.GetAtPath(path);
        var s = imp.defaultSampleSettings; var oldLoad = s.loadType;
        bool changed = oldLoad != AudioClipLoadType.DecompressOnLoad;
        if (changed) { s.loadType = AudioClipLoadType.DecompressOnLoad; imp.defaultSampleSettings = s; imp.SaveAndReimport(); }
        var clip = AssetDatabase.LoadAssetAtPath<AudioClip>(path);
        clip.LoadAudioData();
        int ch = Mathf.Max(1, clip.channels);
        var data = new float[clip.samples * ch];
        if (!clip.GetData(data, 0)) Debug.LogWarning("[Trailer] 오디오를 읽지 못함: " + path);
        int frames = data.Length / ch;
        if (frames == 0) return new float[2];
        // 48kHz 스테레오로
        int outLen = Mathf.CeilToInt(frames * (RATE / (float)clip.frequency));
        var outp = new float[outLen * 2];
        for (int i = 0; i < outLen; i++)
        {
            float src = i * (clip.frequency / (float)RATE);   // int 곱셈은 넘칠 수 있어 float로
            int i0 = Mathf.Min((int)src, frames - 1), i1 = Mathf.Min(i0 + 1, frames - 1); float f = src - i0;
            for (int c = 0; c < 2; c++)
            {
                int cc = Mathf.Min(c, ch - 1);
                outp[i * 2 + c] = Mathf.Lerp(data[i0 * ch + cc], data[i1 * ch + cc], f);
            }
        }
        if (changed) { s.loadType = oldLoad; imp.defaultSampleSettings = s; imp.SaveAndReimport(); }
        return outp;
    }

    static void BuildAudio()
    {
        int n = Mathf.CeilToInt(total * RATE) + RATE;
        mix = new float[n * 2];
        var tracks = new[] { Load("Assets/@Audio/BGM/BGM_F1.mp3"), Load("Assets/@Audio/BGM/BGM_F2.mp3"), Load("Assets/@Audio/BGM/BGM_F3.mp3") };
        var ending = Load("Assets/@Audio/BGM/BGM_Ending.mp3");

        // 곡마다 구간 [시작, 끝] — 1초씩 겹쳐 크로스페이드
        var range = new float[3, 2];
        for (int m = 0; m < 3; m++) { range[m, 0] = float.MaxValue; range[m, 1] = 0; }
        foreach (var s in shots) if (s.music >= 0) { range[s.music, 0] = Mathf.Min(range[s.music, 0], s.start); range[s.music, 1] = Mathf.Max(range[s.music, 1], s.start + s.sec); }
        float endCard = shots[shots.Count - 1].start;
        for (int m = 0; m < 3; m++)
        {
            float a = range[m, 0], b = m == 2 ? endCard + 2.5f : range[m, 1] + 0.5f;   // 마지막 곡은 엔딩 카드에서 서서히
            float inStart = m == 0 ? a : a - 0.5f;
            var tr = tracks[m];
            for (int i = (int)(inStart * RATE); i < (int)(b * RATE) && i < n; i++)
            {
                float t = i / (float)RATE;
                float gain = 0.8f * Ramp(t, inStart, inStart + 1f) * (1f - Ramp(t, b - (m == 2 ? 2.5f : 1f), b));
                int si = (i - (int)(inStart * RATE)) % (tr.Length / 2);
                mix[i * 2] += tr[si * 2] * gain; mix[i * 2 + 1] += tr[si * 2 + 1] * gain;
            }
        }
        int e0 = (int)((endCard + 0.6f) * RATE);
        for (int i = 0; i < ending.Length / 2 && e0 + i < n; i++) { mix[(e0 + i) * 2] += ending[i * 2] * 0.9f; mix[(e0 + i) * 2 + 1] += ending[i * 2 + 1] * 0.9f; }
        // 맨 끝 0.5초는 무음으로
        for (int i = 0; i < mix.Length; i++) mix[i] = Mathf.Clamp(mix[i], -1f, 1f) * (1f - Ramp(i / 2f / RATE, total - 0.5f, total));
    }

    static void AddAudio()
    {
        int per = RATE / FPS;
        using (var buf = new NativeArray<float>(per * 2, Allocator.Temp))
        {
            var b = buf;
            for (int i = 0; i < per * 2; i++) { int idx = audioPos * 2 + i; b[i] = idx < mix.Length ? mix[idx] : 0f; }
            enc.AddSamples(b);
        }
        audioPos += per;
    }
}
```

```hlsl
// 그림 표면 물결: 그림 위에 겹쳐 그리는 투명 판.
// 중심(_Center)에서 원형 파동이 퍼지며(_Progress 0→1) 그 고리 부분만 그림을 일렁이게 비틀어 다시 그리고, 은은하게 빛낸다.
Shader "Gallery/PaintingRipple"
{
    Properties
    {
        [MainTexture] _BaseMap ("Painting", 2D) = "white" {}
        _Center ("Center (UV)", Vector) = (0.5, 0.4, 0, 0)
        _Aspect ("Width / Height", Float) = 1
        _Progress ("Progress", Range(0, 1)) = 0
        _MaxRadius ("Max Radius", Float) = 0.9
        _Width ("Ring Width", Float) = 0.07
        _Amplitude ("Distortion", Float) = 0.015
        _Frequency ("Wave Frequency", Float) = 60
        _GlowColor ("Glow Color", Color) = (1, 0.95, 0.8, 1)
        _Glow ("Glow", Range(0, 1)) = 0.15
        _Brightness ("Painting Brightness", Range(0, 1.5)) = 0.8
        _Intensity ("Intensity", Range(0, 1)) = 1
    }
    SubShader
    {
        Tags { "RenderType" = "Transparent" "Queue" = "Transparent" "RenderPipeline" = "UniversalPipeline" }
        Blend SrcAlpha OneMinusSrcAlpha
        ZWrite Off
        Cull Back

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            TEXTURE2D(_BaseMap); SAMPLER(sampler_BaseMap);
            CBUFFER_START(UnityPerMaterial)
                float4 _BaseMap_ST;
                float4 _Center;
                float _Aspect, _Progress, _MaxRadius, _Width, _Amplitude, _Frequency, _Intensity, _Glow, _Brightness;
                half4 _GlowColor;
            CBUFFER_END

            struct Attributes { float4 positionOS : POSITION; float2 uv : TEXCOORD0; UNITY_VERTEX_INPUT_INSTANCE_ID };
            struct Varyings { float4 positionCS : SV_POSITION; float2 uv : TEXCOORD0; UNITY_VERTEX_OUTPUT_STEREO };

            Varyings vert(Attributes i)
            {
                Varyings o;
                UNITY_SETUP_INSTANCE_ID(i);
                UNITY_INITIALIZE_VERTEX_OUTPUT_STEREO(o);   // VR 싱글 패스
                o.positionCS = TransformObjectToHClip(i.positionOS.xyz);
                o.uv = i.uv;
                return o;
            }

            half4 frag(Varyings i) : SV_Target
            {
                float2 d = i.uv - _Center.xy;
                d.x *= _Aspect;                       // 세로로 긴 그림에서도 동그란 파동
                float dist = length(d);
                float radius = _Progress * _MaxRadius;
                float ring = exp(-pow((dist - radius) / _Width, 2));
                float fade = (1 - _Progress) * _Intensity;

                float2 dir = dist > 1e-4 ? d / dist : 0;
                dir.x /= _Aspect;
                float2 uv = i.uv + dir * sin((dist - radius) * _Frequency) * _Amplitude * ring;

                half4 col = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, uv * _BaseMap_ST.xy + _BaseMap_ST.zw);
                col.rgb *= _Brightness;                         // 조명 받은 원래 그림 밝기에 맞춤
                col.rgb += _GlowColor.rgb * ring * _Glow;       // 고리 부분만 은은하게
                col.a = saturate(ring * fade);
                return col;
            }
            ENDHLSL
        }
    }
}
```
